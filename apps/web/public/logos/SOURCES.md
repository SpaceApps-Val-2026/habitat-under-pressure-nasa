# Origin and usage rules of the logos

**In this public repository, only the files marked “Yes” or “Unclear” below are distributed and shown.** Those
marked “Needs permission” are listed under `held` in `logos.json`, their files are not included, and the footer
writes their names as text. The table keeps every row as the record of what was read.

Downloaded on **2026-11-15** with plain GET requests and a generic user agent; no registration, form or
acceptance of terms. “Can it be shown?” is a reading of the owner's rule, not a permission. The logos belong
to their owners and are not covered by the project's Apache 2.0 licence.

## Notes

1. **Space Apps.** `spaceappschallenge.org` (the `/brand` page with the current logos and the page of the
   València event) could not be reached when the files were downloaded. The PNG comes from the legacy (2022)
   site of the same domain, is the white version of the default logo and reads “International Space Apps
   Challenge”, while the 2026 guide calls the event “NASA Space Apps Challenge”. It should be replaced by the
   current file from <https://www.spaceappschallenge.org/brand>. There is no version for a light background: in
   the light theme the footer does not draw this logo.
2. **Logo of the València event:** not found. The key `space-apps-valencia` is still free.
3. **NASA** offers a specific route: the NASA Data Insignia (“DATA AT WORK”) for products that use public NASA
   data, with prior approval and a mandatory disclaimer. `nasa.svg` is not that insignia.

## Normalisation

- SVG: only the root `<svg>` tag changes: `viewBox` fitted to the content box and `width`/`height` to a box
  32 px high. Colours, paths and elements are intact.
- PNG: fully transparent margins trimmed and reduced to 112 px high when the original was taller; never
  enlarged. No background removed: all were already transparent.
- Variants: `*.dark.*` for a dark background and `*.light.*` for a light one, always the version the owner
  publishes; a single file without a suffix serves both themes.
